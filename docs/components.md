# Components

The root export provides server-safe shells, entity/statement views, seven-kind search results, content views, readiness, revision history, task packets, and explicit loading, empty, error, and permission states.

The client export provides named-operation screens and editors. `ResourceBrowser`, `AnnotationBrowser`, `PromptBrowser`, `MemoryBrowser`, and `TaskBrowser` load collections and authorized details through Workshop. `TaskWorkspace` covers claim, idempotent owner release, completion, archive, revision conflict, and expired leases.

The site export is route-free screen composition. Hosts decide URLs, navigation, authentication, and deployment.
